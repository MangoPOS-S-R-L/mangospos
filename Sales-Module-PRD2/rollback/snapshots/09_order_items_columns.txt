Notas para PRD 2:

- `tax_rate` es la tasa que se aplica al ítem (puede ser ITBIS solo o
  ITBIS+propina, según cómo lo asigna `fn_add_item_from_menu` hoy).
- `original_tax_rate` es la tasa con la que se compuso el precio (solo
  relevante en modo inclusive para extraer base estable).
- En PRD 2 vamos a redefinir el contrato:
  * `tax_rate` = SUMA de todas las tasas que aplican a este item para
    este origin (ITBIS si aplica + Propina si aplica + cualquier otro).
  * `original_tax_rate` = SUMA de todas las tasas asociadas al producto
    (no filtradas por origin) — para que el cálculo inclusive con base
    estable siga funcionando aunque el origin desactive un impuesto.
  * `tax` = subtotal × tax_rate / 100 (consolidado, ya no hay
    service_fee separado por línea).
- Sin columna `service_fee` por línea: PRD 2 mantiene esto. La propina
  se incluye dentro de `tax` cuando aplica.
