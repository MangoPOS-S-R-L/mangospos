MANGOPOS - CARACTERISTICAS Y PLANES PARA LANDING

Nota:
Este documento esta pensado como base comercial para la landing.
Se apoya en los modulos reales del sistema y en una propuesta de planes
que puedes ajustar despues con precios, limites y beneficios comerciales.

========================================================================
1. DESCRIPCION GENERAL DEL SISTEMA
========================================================================

MangoPOS es un sistema POS para restaurantes y negocios de comida que
centraliza ventas, mesas, cocina, caja, productos, usuarios, impresion y
configuracion operativa en una sola plataforma.

Esta disenado para operar de forma rapida en pantalla tactil, reducir
errores en la toma de pedidos y darle al negocio mas control sobre su
operacion diaria.

========================================================================

========================================================================

tiene MangoPOS y en los upgrades que el sistema puede vender mejor.

PLAN 1 - BASE
Ideal para negocios que quieren comenzar a operar con orden y velocidad.

Incluye:
- Punto de venta
- Venta por mesas y zonas
- Venta rapida
- Venta manual
- Base comercial para delivery y self service
- Carrito con calculos automaticos
- Busqueda y filtro de productos
- Modificadores y notas por producto
- Envio de comandas a cocina
- Division de cuenta
- Precuenta
- Cobros en efectivo, tarjeta y transferencia
- Apertura y cierre de caja
- Ingresos y egresos
- KDS de cocina
- Gestion de productos
- Gestion de categorias
- Gestion de menus
- Gestion de impuestos
- Gestion de usuarios y roles base
- Configuracion de zonas y mesas
- Configuracion de impresion
- 1 negocio / 1 sucursal
- Soporte base

Copy sugerido:
Todo lo esencial para vender, cobrar y operar tu restaurante en un solo
lugar.

PLAN 2 - PRO
Ideal para negocios que necesitan mas control operativo y administracion.

Incluye todo lo del Plan Base, mas:
- Gestion ampliada de empleados
- Permisos avanzados por usuario
- Recetas
- Mayor control de impresion por areas
- Configuracion operativa mas completa
- Mayor organizacion del catalogo y del menu
- Clientes y base para historial de compras
- Acompanamiento de implementacion
- Mas usuarios operativos
- Soporte prioritario

Copy sugerido:
Mas control, mas orden y mas capacidad para crecer sin complicar la
operacion.

PLAN 3 - ENTERPRISE
Ideal para marcas, cadenas o negocios que quieren una operacion mas
robusta y escalable.

Incluye todo lo del Plan Pro, mas:
- Multi-sucursal
- Mayor control administrativo por sede
- Parametrizacion avanzada del sistema
- Implementacion acompanada
- Soporte premium
- Prioridad en mejoras
- Integraciones o adaptaciones a medida
- Activacion de modulos avanzados segun alcance comercial
- Preparacion para reportes avanzados
- Preparacion para inventario, compras y promociones
- Preparacion para fidelizacion, creditos y gift cards

Copy sugerido:
La version mas completa de MangoPOS para operaciones que necesitan
control, escalabilidad y acompanamiento cercano.
